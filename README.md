# AliLauncher

**AliLauncher** — бесплатный лаунчер для игры **Minecraft**, который делает запуск быстрым и удобным: установка, обновление и настройка клиента происходят автоматически.

## ✨ Возможности

- **Быстрый запуск** — клиент Minecraft устанавливается, обновляется и запускается в один клик.
- **Автообновление** — новые версии загружаются автоматически.
- **Гибкие настройки** — управление памятью, версией Java и параметрами запуска.
- **Многопрофильность** — несколько аккаунтов и наборов настроек.
- **Простой интерфейс** — ничего лишнего, легко разобраться.
- **Кроссплатформенность** — Windows и Linux.

## 📦 Установка

### Windows

1. Скачайте `AliLauncher-<версия>-Setup.exe`.
2. Запустите файл и следуйте шагам мастера установки.
3. Откройте лаунчер, войдите в аккаунт и играйте.

### Linux

1. Скачайте `AliLauncher-<версия>-Linux-Setup.tar.gz`.
2. Распакуйте архив:
   ```bash
   tar -xzvf AliLauncher-<версия>-Linux-Setup.tar.gz
   ```
3. Запустите исполняемый файл лаунчера.
4. При необходимости закрепите приложение в меню.

## 🖥 Системные требования

- **ОС:** Windows 7+ (64-bit) или современный дистрибутив Linux.
- **Память:** от 2 ГБ (рекомендуется 4+ ГБ).
- **Диск:** несколько ГБ свободного места с учётом файлов игры.
- **Java:** установите при необходимости или используйте встроенную.
